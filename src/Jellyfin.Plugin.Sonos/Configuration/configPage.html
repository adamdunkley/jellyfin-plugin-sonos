Master switch. When off, discovery and playback stop.
Fallback Jellyfin user for unattended Play To. Authenticated /Sonos/Queue/Play calls use the calling user instead.
Address speakers use to fetch Cloud Queue and audio. Must be a LAN HTTP URL the speaker can route to — not localhost, not a Docker bridge IP, and not a reverse-proxy HTTPS hostname unless speakers can complete TLS to it. Include the server base path if Jellyfin is configured with one.
Comma-separated IPs. Use these when multicast mDNS/SSDP cannot reach the speakers (for example Jellyfin in a Docker bridge). Seed IPs are then the primary discovery path.
Used when a library file is outside Sonos's supported matrix (DSD, hi-res FLAC, odd containers).
Comma-separated RINCON ids that should never be exposed or controlled.
Writes Cloud Queue paths, versions, and control commands to the Jellyfin log. Never logs stream tokens or API keys.

If speakers are discovered but commands return 403, disable LAN authentication in the Sonos app (privacy / third-party LAN integrations). No Sonos developer key is required for LAN S2 control.
